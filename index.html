Research Project 2025 - Present

Ariadne2: Reinforcement Learning for Single-Robot Autonomous Exploration

This project formulates exploration in unknown occupancy-grid environments as a graph-structured sequential decision problem over dynamic frontier viewpoints. The framework combines frontier clustering, Gaussian viewpoint proposal, Transformer encoding, pointer-style action selection, A*-constrained execution, Soft Actor-Critic, expert-aligned rewards, and a Ray-based distributed rollout pipeline.

CV

Evaluation is organized around 4,000 training maps and 100 held-out test maps, with cluster-wise candidate pruning and GT-guided expert path alignment used to improve training signal quality.

Preference-Conditioned Optimization

Research framework for multi-objective combinatorial optimization across MOMTSP, HCVRP, FJSP, and FFSP, using Hydra-managed experiments and preference scans.
